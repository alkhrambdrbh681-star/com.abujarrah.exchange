# صَرّاف | محوّل العملات

تطبيق Flutter بسيط باللغة العربية لتحويل المبالغ بين مجموعة من العملات وعرض سعر التحويل المقابل.

## المزايا

- واجهة عربية باتجاه من اليمين إلى اليسار.
- تحويل فوري أثناء إدخال المبلغ.
- اختيار العملة وتبديل عملتي التحويل.
- قائمة بعملات شائعة.
- لا يحتاج إلى حزم إضافية لتشغيل النسخة الأولية.

> **تنبيه:** أسعار الصرف في هذه النسخة تجريبية وثابتة، وليست أسعارًا مباشرة أو مخصصة للاستخدام المالي. يلزم ربط التطبيق بمصدر أسعار موثوق وتحديث البيانات قبل استخدامه الفعلي.

## التشغيل

تأكد من تثبيت Flutter، ثم شغّل من مجلد المشروع:

```bash
flutter pub get
flutter run
```

## العملات التجريبية

الدولار الأمريكي، اليورو، الريال السعودي، الدرهم الإماراتي، الدينار الأردني، والجنيه المصري.
